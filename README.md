# Loopy Sweeper

A private, Loopy-themed Minesweeper game built with React, TypeScript, Vite, and Vinext.

## Development

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Quality checks:

```bash
npm test
npm run typecheck
npm run lint
npm run build
```

## Controls

- Click or tap to reveal a cell.
- Right-click or long-press to flag a cell.
- With keyboard focus on the board, use arrow keys to move, Enter or Space to reveal, and F to flag.
